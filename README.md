Dry Bean Classification
Порівняння PyTorch, TensorFlow, PaddlePaddle та MindSpore
Проєкт демонструє, як чотири фреймворки глибокого навчання розв’язують одну й ту саму задачу — класифікацію семи сортів квасолі за набором числових характеристик.

Для порівняння використовується однакова архітектура нейронної мережі та спільний набір даних. Кожна модель навчається 5 разів, після чого програма порівнює точність, F1-міру та час навчання.
Датасет
Dry Bean Dataset — реальний набір даних із UCI Machine Learning Repository.
- 13 611 зразків
- 16 числових ознак
- 7 класів
Дані розділяються на навчальну, валідаційну та тестову вибірки. Масштабування ознак виконується на основі навчальної вибірки.
Модель
Для кожного фреймворку використовується однакова повнозв’язна нейронна мережа з трьома прихованими шарами:
16 входів → 16 → 32 → 64 → 7 класів
Моделі навчаються протягом 100 епох з оптимізатором Adam. Для порівнюваності використовуються спільні початкові ваги та однаковий порядок навчальних прикладів.
Швидкий старт
Відкрийте термінал у папці проєкту та виконайте:
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install torch==2.9.1
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run_all.py
run_all.py підготує дані, запустить експерименти, збереже метрики та згенерує графіки. За повторного запуску вже перевірені результати не обчислюються повторно.
Перед запуском переконайтеся, що файл Dry_Bean_Dataset.xlsx є в корені проєкту.

Результати
Після запуску з’являться:
Шлях	Вміст
results_v2/all_runs.csv	Результати всіх 20 запусків
results_v2/comparison_mean_sd.csv	Середні значення та стандартні відхилення
results_v2/comparison_formatted.csv	Готова порівняльна таблиця
figures/	Графіки навчання, матриці помилок і порівняння моделей
results_v2/logs/	Журнали запусків


Окремо перевірити збережені результати можна командою:
.\.venv\Scripts\python.exe verify_results.py
Структура проєкту
DryBean/
├── common.py                  # Спільні функції та налаштування
├── prepare_data.py            # Підготовка даних
├── train_pytorch.py           # PyTorch
├── train_tensorflow.py        # TensorFlow
├── train_paddlepaddle.py      # PaddlePaddle
├── train_mindspore.py         # MindSpore
├── run_all.py                 # Запуск експериментів
├── compare_results.py         # Порівняння та графіки
├── verify_results.py          # Перевірка результатів
├── requirements.txt           # Залежності
└── Dry_Bean_Dataset.xlsx      # Вхідний датасет
