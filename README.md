🫘 Dry Bean Classification
Порівняння PyTorch, TensorFlow, PaddlePaddle та MindSpore
Одна задача · Одна архітектура · Чотири фреймворки


📖 Про проєкт
Проєкт демонструє, як чотири фреймворки глибокого навчання розв'язують одну задачу — класифікацію семи сортів квасолі за числовими характеристиками зерен.

Для чеснішого порівняння у всіх реалізаціях використовуються однакова архітектура нейромережі, спільні дані, початкові ваги та порядок навчальних прикладів. Кожна модель навчається п'ять разів із різними початковими значеннями генератора випадкових чисел.

Після запуску програма збирає метрики, порівнює результати й автоматично створює графіки.
🔍 Що порівнюємо
- Accuracy — частку правильно класифікованих зразків.
- Macro-F1 — збалансовану оцінку якості для всіх семи класів.
- Час навчання — швидкість виконання реалізації в заданому середовищі.
🧬 Дані та архітектура
Використовується Dry Bean Dataset із репозиторію UCI Machine Learning Repository.
Характеристика	Значення
Кількість зразків	13 611
Числові ознаки	16
Класи квасолі	7
Поділ даних	Навчальна / валідаційна / тестова вибірки
Кількість запусків	5 для кожного фреймворку (20 загалом)


В усіх чотирьох реалізаціях застосовується повнозв'язна нейронна мережа з трьома прихованими шарами:
16 ознак → 16 нейронів → 32 нейрони → 64 нейрони → 7 класів
Модель використовує ReLU, оптимізатор Adam і навчається протягом 100 епох. Масштабування ознак виконується за параметрами, обчисленими лише на навчальній вибірці.
🚀 Швидкий старт
Потрібні Python 3.12 та файл Dry_Bean_Dataset.xlsx у корені проєкту.

Відкрийте PowerShell у папці репозиторію й виконайте:
# Створити віртуальне середовище
python -m venv .venv

# Встановити залежності
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install torch==2.9.1
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# Запустити всі експерименти
.\.venv\Scripts\python.exe run_all.py
Скрипт run_all.py автоматично підготує дані, виконає 20 запусків, збереже метрики та побудує графіки. Під час повторного запуску вже перевірені результати не обчислюються заново.
📊 Результати порівняння
Наведено середні значення за п'ятьма запусками кожного фреймворку:
Фреймворк	Accuracy	Macro-F1	Середній час навчання
PyTorch	92,33 %	93,52 %	5,38 с
TensorFlow	92,36 %	93,54 %	4,75 с
PaddlePaddle	92,36 %	93,54 %	4,44 с
MindSpore	92,34 %	93,52 %	21,05 с


[!NOTE]
Якість класифікації виявилася майже однаковою. Час навчання залежить від реалізації, версій бібліотек та обладнання; наведені результати не є універсальним рейтингом швидкодії фреймворків.

Після виконання проєкт створює такі файли:
Шлях	Що містить
results_v2/all_runs.csv	Метрики всіх 20 запусків
results_v2/comparison_mean_sd.csv	Середні значення та стандартні відхилення
results_v2/comparison_formatted.csv	Готову порівняльну таблицю
results_v2/logs/	Журнали виконання
figures/	Графіки навчання, матриці помилок і порівняння


🗂️ Структура проєкту
DryBean/
├── common.py                 # Спільна логіка, параметри й метрики
├── prepare_data.py           # Підготовка набору даних
├── train_pytorch.py          # Реалізація PyTorch
├── train_tensorflow.py       # Реалізація TensorFlow
├── train_paddlepaddle.py     # Реалізація PaddlePaddle
├── train_mindspore.py        # Реалізація MindSpore
├── run_all.py                # Повний запуск експериментів
├── compare_results.py        # Таблиці та порівняльні графіки
├── verify_results.py        # Перевірка результатів
├── requirements.txt         # Залежності проєкту
└── Dry_Bean_Dataset.xlsx     # Вхідні дані
Додаткові команди
# Запустити один експеримент
.\.venv\Scripts\python.exe train_pytorch.py --seed 42

# Запустити лише PyTorch (5 експериментів)
.\.venv\Scripts\python.exe run_all.py --framework PyTorch

# Перевірити збережені результати
.\.venv\Scripts\python.exe verify_results.py

# Повторно згенерувати порівняння та графіки
.\.venv\Scripts\python.exe compare_results.py
