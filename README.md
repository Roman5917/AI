🫘 Dry Bean Classification
Порівняння PyTorch, TensorFlow, PaddlePaddle та MindSpore

4 фреймворки · 1 нейромережа · 20 запусків · 1 набір даних

Проєкт порівнює чотири фреймворки глибокого навчання на однаковій задачі: класифікації семи сортів квасолі за числовими характеристиками зерен. У кожному фреймворку навчається нейромережа з однаковою архітектурою. Результати п’яти запусків для кожного інструмента об’єднуються в таблиці та графіки.
📌 Що є в проєкті
- PyTorch, TensorFlow, PaddlePaddle та MindSpore — чотири реалізації тієї самої моделі.
- Спільні умови — однакові дані, початкові ваги та порядок навчальних прикладів.
- Автоматичний запуск — підготовка даних, 20 експериментів, обчислення метрик.
- Візуалізація — криві навчання, матриці помилок та порівняльні діаграми.
🚀 Швидкий старт
Інструкція для PowerShell у Windows. Рекомендована версія — Python 3.12.

1. Відкрийте термінал у кореневій папці проєкту та створіть віртуальне середовище:
python -m venv .venv
2. Встановіть залежності:
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install torch==2.9.1 --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
3. Запустіть усі експерименти:
.\.venv\Scripts\python.exe run_all.py
Готово. run_all.py підготує датасет, послідовно запустить 20 експериментів, збереже метрики й побудує графіки. Повторний запуск пропускає результати, що вже пройшли перевірку.
Перед запуском: переконайтеся, що Dry_Bean_Dataset.xlsx знаходиться в корені проєкту. Активувати .venv окремою командою не потрібно.

У кожному фреймворку використовується однакова повнозв’язна нейронна мережа з трьома прихованими шарами:
16 входів  →  16 нейронів  →  32 нейрони  →  64 нейрони  →  7 класів

🛠️ Додаткові команди
Запустити один експеримент PyTorch:
.\.venv\Scripts\python.exe train_pytorch.py --seed 42
Запустити лише PyTorch (усі 5 запусків):
.\.venv\Scripts\python.exe run_all.py --framework PyTorch
Перевірити отримані результати:
.\.venv\Scripts\python.exe verify_results.py
Повторно побудувати підсумкові таблиці й графіки:
.\.venv\Scripts\python.exe compare_results.py
